# difficulty-routing

把一個任務拆成小步驟，並把每一步交給能可靠完成它的最低推理強度／最便宜模型，在不損失準確度的前提下降低成本。

## 安裝

**Claude Code：** 把 `difficulty-routing/` 資料夾複製到 `~/.claude/skills/`（或專案的 `.claude/skills/`）。

**Grok Bot：** 請機器人把它存成一個 skill（貼上 `SKILL.md` 的內容）。

# difficulty-routing

Split a task into small steps and route each one to the lowest reasoning effort / cheapest model that can do it reliably, cutting cost without losing accuracy.

## Install

**Claude Code:** copy the `difficulty-routing/` folder into `~/.claude/skills/` (or the project's `.claude/skills/`).

**Grok Bot:** ask the bot to save it as a skill (paste the `SKILL.md` content).
